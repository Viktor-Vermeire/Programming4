# Minigin

Minigin was the basis of this project.
Multiple alterations have been made.
## SceneManager & Scene
Scenemanager now only updates the active scene, and can support switching scenes in a safe matter.
A scene can now also contain a functor to execute necessary transitional code.

## Highscore keyboard
A keyboard is available for gamepad and keyboard to enter your name.


# Controls
- WASD / Gamepad arrow buttons for UP,LEFT,DOWN and RIGHT respectively
- E / A to shoot DigDug's pump || breathe Fyras' flames || confirm keyboard presses
- Q / START to save your highscore
- F1 to skip the current level
- F2 to mute the sound
